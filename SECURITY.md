# Security

## Scope and Intent

Phalanx contains runnable demonstrations and reference implementations, not hardened production services. It is not designed or configured for untrusted public network exposure.

## Project Security Notes

### Phalanx: Simulation environment

Phalanx's optional range / simulation environment is intended for loopback-only use (`localhost` / `127.0.0.1`). It should not be exposed to untrusted networks or unauthenticated users.

## Reporting a Vulnerability

Please open a private GitHub security advisory for `anvil008/phalanx` at https://github.com/anvil008/phalanx/security/advisories rather than filing a public issue. Do not include active credentials in reports, screenshots, fixtures, or logs.
